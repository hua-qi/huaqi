**📚 课程：Python 基础**
**📌 知识点：条件判断与逻辑运算符的短路特性**

在 Python 的 `if` 语句或 `while` 循环中，我们经常用 `and` 和 `or` 连接多个条件。但你知道吗？Python 在判断这些逻辑表达式时，**一旦结果确定，就会立刻停下来，不再计算后面的条件**——这就是“短路求值”。

---

**📝 题目 1（选择题）**

```python
x = 5
y = 0
result = (x > 0) or (y / x > 1)
```

请问上面代码执行后，会发生什么？

A. 程序正常运行，`result` 为 `True`
B. 程序报错 `ZeroDivisionError`（除零错误）
C. 程序正常运行，`result` 为 `False`
D. 程序报错 `NameError`

---

**📝 题目 2（简答题）**

请解释：为什么在 Python 中写 `if user and user.is_active:` 比直接写 `if user.is_active:` 更安全？这背后利用了哪个逻辑特性？

---

**✅ 答案解析**

**答案 1：A**
- `x > 0` 为 `True`。
- 对于 `or` 运算，只要第一个条件为 `True`，整个结果就已经确定为 `True`，所以 Python **不会去计算**后面的 `y / x > 1`。
- 因此不会触发除零错误，`result` 直接被赋值为 `True`。

**答案 2：**
- 利用了 `and` 的**短路特性**。
- 如果 `user` 为 `None`（或任何假值），Python 会立即将整个表达式判定为假，**不再执行** `user.is_active` 这个属性访问。
- 如果直接写 `user.is_active`，当 `user` 是 `None` 时，就会抛出 `AttributeError`（属性不存在错误）。
- 所以 `if user and user.is_active:` 是一种常见的**防御性编程**写法。
