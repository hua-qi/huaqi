### 题目 1（选择题）
以下代码的输出结果是：
```python
for i in range(3):
    if i % 2 == 0:
        print("偶数", i)
    else:
        print("奇数", i)
```

A. 偶数 0  
   奇数 1  
   偶数 2  

B. 奇数 0  
   偶数 1  
   奇数 2  

C. 偶数 0  
   偶数 1  
   偶数 2  

D. 奇数 0  
   奇数 1  
   奇数 2

### 题目 2（简答题）
请写出一个 Python 代码片段，使用 `for` 循环和 `if` 语句，打印出 1 到 10 之间所有能被 3 整除的数字。

---

### 答案解析

**题目 1 答案：A**  
- `range(3)` 生成 0, 1, 2  
- 0 % 2 == 0 → 偶数 0  
- 1 % 2 != 0 → 奇数 1  
- 2 % 2 == 0 → 偶数 2  

**题目 2 参考代码：**
```python
for num in range(1, 11):
    if num % 3 == 0:
        print(num)
```
输出：3, 6, 9
