**📝 题目 1（选择题）**

以下 Python 代码的输出是什么？
```python
x = 5
if x > 3 and x < 10 or x == 2:
    print("A")
else:
    print("B")
```

A. A  
B. B  
C. 语法错误  
D. 无法确定

**📝 题目 2（简答题）**

假设你有一个变量 `age = 20` 和 `has_license = False`。  
请写一行代码，判断这个人是否“可以合法开车”（年龄≥18 **并且** 有驾照）。  
如果条件满足，打印 `"可以开车"`，否则打印 `"不可以开车"`。

---

**💡 答案解析**

**题目 1 答案：A**

解析：这道题考察的是 `and` 和 `or` 的优先级。在 Python 中，`and` 的优先级高于 `or`，所以实际执行顺序是：
1. `x > 3 and x < 10` → `True and True` → `True`
2. `True or x == 2` → `True or False` → `True`
3. 所以输出 `"A"`

**题目 2 答案：**
```python
print("可以开车" if age >= 18 and has_license else "不可以开车")
```
或者用传统 if 语句：
```python
if age >= 18 and has_license:
    print("可以开车")
else:
    print("不可以开车")
```

解析：这里 `and` 要求两个条件同时为真。因为 `has_license` 是 `False`，所以无论年龄如何，结果都是“不可以开车”。
