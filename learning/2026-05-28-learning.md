## 复习题：Python 流程控制与逻辑运算

**知识点回顾：** 你刚学完条件判断（if/elif/else）和逻辑运算符（and/or/not）。这可是编程的 "决策大脑" 哦！

---

### 题目1（选择题）
以下代码的输出结果是什么？
```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("欢迎入场")
elif age >= 18 and not has_ticket:
    print("请先买票")
else:
    print("未成年人禁止入场")
```

A. "欢迎入场"
B. "请先买票"
C. "未成年人禁止入场"
D. 语法错误

---

### 题目2（简答题）
写一段代码：判断一个整数 `num = 15` 是否同时满足以下两个条件：
1. 大于 10
2. 能被 3 整除

如果满足，打印 "符合条件"，否则打印 "不符合条件"。

---

## 答案解析

**题目1 答案：A**
- 解析：`age >= 18` 为 True，`has_ticket` 为 True，所以 `True and True` 结果为 True，执行第一个分支。

**题目2 参考代码：**
```python
num = 15
if num > 10 and num % 3 == 0:
    print("符合条件")
else:
    print("不符合条件")
```
- 解析：`num % 3 == 0` 用来判断是否能被 3 整除，当两个条件都为 True 时，打印 "符合条件"。
