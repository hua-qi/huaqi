**课程**：Python 基础语法与数据类型  
**知识点**：可变与不可变数据类型（Mutable vs Immutable）

---

### 复习题

**题目 1（选择题）**：  
以下哪个操作会**改变**原变量的值？  
A. `x = [1, 2, 3]; x.append(4)`  
B. `y = (1, 2, 3); y = y + (4,)`  
C. `z = "hello"; z.upper()`  
D. `w = 5; w += 3`

**题目 2（简答题）**：  
请解释为什么下面的代码会报错，并说明如何修复：  
```python
t = (1, 2, 3)
t[0] = 100
```

---

### 答案解析

**题目 1 答案：A**  
- A ✅：列表是可变类型，`append()` 直接修改原列表对象，不创建新对象。  
- B ❌：元组是不可变类型，`y = y + (4,)` 会创建一个新的元组，原元组不变。  
- C ❌：字符串是不可变类型，`upper()` 返回一个新字符串，原字符串不变。  
- D ❌：整数是不可变类型，`w += 3` 实际是创建一个新的整数对象并重新绑定给 `w`，原整数对象不变。

**题目 2 解析**：  
元组是**不可变**数据类型，一旦创建，其元素不能被修改。  
- 报错原因：试图对元组进行索引赋值操作。  
- 修复方法：如果需要一个可以修改元素的序列，应该使用**列表**：  
  ```python
  t = [1, 2, 3]
  t[0] = 100  # 成功
  ```
