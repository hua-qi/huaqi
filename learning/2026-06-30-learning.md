**知识点：逻辑运算符 `and`、`or`、`not` 与短路求值**

**题目 1（选择题）：**
以下代码的输出是什么？
```python
x = 0
y = 10
result = x and y
print(result)
```
A. 0  
B. 10  
C. True  
D. False  

**题目 2（简答题）：**
请解释为什么上面的代码会输出那个结果？这体现了 Python 的什么特性？

---

**答案解析：**

**题目 1 答案：A. 0**

**题目 2 解析：**
Python 的 `and` 运算符遵循**短路求值**规则：
- 当 `x` 为假值（0、None、空序列等）时，`and` 直接返回 `x` 的值，不再计算 `y`
- 当 `x` 为真值时，才返回 `y` 的值
这里 `x = 0` 是假值，所以 `and` 短路，返回 `0`

这个特性在日常编码中很实用，比如：
```python
# 安全地访问可能为 None 的对象
user = get_user() and get_user().name  # 如果 get_user() 返回 None，不会调用 .name
```
