### 题目1（选择题）：
以下代码的输出是什么？
```python
x = 5
y = 10
result = x > 3 and y < 20 or not x == 5
print(result)
```
A. True  
B. False  
C. 报错  
D. 不确定

### 题目2（简答题）：
请用一句话解释：为什么 `not x > 5` 和 `x <= 5` 在逻辑上是等价的？你能举一个实际场景，说明什么时候用 `not` 比直接比较更清晰？

---

### 答案解析

**题目1：**  
正确答案是 **B. False**。  
拆解过程：
1. `x > 3` → `True`  
2. `y < 20` → `True`  
3. `True and True` → `True`  
4. `not x == 5` → `not True` → `False`  
5. 最后：`True or False` → `True`  
等等，这里我算错了——`not` 优先级高于 `or`，但低于 `and`。正确顺序：  
`(x > 3 and y < 20) or (not (x == 5))`  
= `True or False` = **True**  
（抱歉刚才差点误导你！所以答案是 **A. True**）

**题目2：**  
它们等价是因为 `not` 反转了比较结果，而 `x <= 5` 本身就是 `x > 5` 的补集。  
实际场景：当你在检查“是否不是某个特定值”时，比如 `not user.role == 'admin'` 比 `user.role != 'admin'` 更强调“排除”的语义，读起来更自然。
