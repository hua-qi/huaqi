**课程**：Python基础语法与数据类型
**知识点**：可变对象（列表）与不可变对象（字符串、元组）的区别

---

**题目1（选择题）**：
以下代码运行后，`a` 的值是什么？
```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```
A. `[1, 2, 3]`
B. `[1, 2, 3, 4]`
C. 报错
D. `None`

**题目2（简答题）**：
请解释为什么下面这段代码中，`x` 的值没有改变，而上面的 `a` 却变了？
```python
x = "hello"
y = x
y = y + " world"
print(x)  # 输出 "hello"
```

---

**答案解析**：

**题目1答案：B. [1, 2, 3, 4]**
- 列表是**可变对象**。`b = a` 并没有复制列表，而是让 `b` 指向了 `a` 的同一个内存地址。
- 所以 `b.append(4)` 修改的是这个共享的列表，`a` 自然也跟着变了。

**题目2要点**：
- 字符串是**不可变对象**。`y = x` 让 `y` 指向了 `"hello"` 的内存地址。
- 但 `y = y + " world"` 实际上是**创建了一个新的字符串** `"hello world"`，并让 `y` 指向这个新对象。
- 原来的 `x` 仍然指向 `"hello"`，所以 `x` 没变。

**核心区别**：可变对象可以“原地修改”，不可变对象只能“重新赋值”。

继续加油！理解可变与不可变，就像理解“借书”和“复印书”的区别——前者别人改了你也会看到变化，后者改的是副本，原版纹丝不动。这个认知会陪你走很远。
