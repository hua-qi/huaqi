**知识点：可变 vs 不可变数据类型**

在Python中，数据类型分为可变（mutable）和不可变（immutable）两类。理解这个区别，能帮你避免很多“为什么我的变量变了？”的困惑。

---

**题目1（选择题）：**
以下哪个操作会**改变**原变量的值？
A. `a = [1, 2, 3]; a.append(4)`
B. `b = "hello"; b.upper()`
C. `c = (1, 2, 3); c + (4,)`
D. `d = 5; d + 3`

**题目2（简答题）：**
为什么说字符串在Python中是不可变的？请用一个代码例子说明“试图修改字符串”时会发生什么。

---

**答案解析：**

**题目1答案：A**
- A：列表是可变类型，`append()`会直接修改原列表对象
- B：字符串不可变，`upper()`返回新字符串，原字符串不变
- C：元组不可变，`+`操作创建新元组
- D：整数不可变，`+`返回新整数

**题目2参考示例：**
```python
s = "hello"
# s[0] = "H"  # 这行会报错：TypeError: 'str' object does not support item assignment
s = s.capitalize()  # 正确的做法：重新赋值
print(s)  # "Hello"
```
字符串像一块刻好的石碑——你不能擦掉某个字母重写，只能整块换新的。
