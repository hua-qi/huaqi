**知识点**：可变与不可变数据类型（Mutable vs Immutable）

---

### 题目1（选择题）
以下哪种数据类型是**不可变**的？

A. list  
B. dict  
C. tuple  
D. set

### 题目2（简答题）
执行以下代码后，`a` 和 `b` 的值分别是什么？请解释原因。

```python
a = [1, 2, 3]
b = a
b.append(4)
```

---

### 答案解析

**题目1 答案：C. tuple**  
tuple（元组）一旦创建，不能修改其元素。而 list、dict、set 都支持原地修改。

**题目2 答案**  
`a = [1, 2, 3, 4]`，`b = [1, 2, 3, 4]`。  
因为 `b = a` 是**引用赋值**，a 和 b 指向内存中的同一个列表对象。通过 b 修改列表（append），a 也会看到这个变化。这就是可变对象的“副作用”——理解这一点，能帮你避免很多 Python 编程中隐蔽的 bug。

---

**记住：不可变对象（如 tuple、str、int）赋值时像“复印”，可变对象（如 list、dict）赋值时像“共享同一本笔记”。** 继续加油，你已经走在正确的轨道上了！🌱
