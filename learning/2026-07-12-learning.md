## 知识点：列表的切片（Slicing）

列表切片是 Python 数据处理的基础利器，它能让你优雅地提取、复制甚至反转数据。

### 🧠 复习题 1（选择题）

以下代码的输出是什么？

```python
my_list = [10, 20, 30, 40, 50, 60]
result = my_list[1:4:2]
print(result)
```

A. [20, 30, 40]  
B. [20, 40]  
C. [10, 30, 50]  
D. [20, 30]

### 🧠 复习题 2（简答题）

请用一行切片代码，将列表 `data = [1, 2, 3, 4, 5, 6, 7]` 反转，得到 `[7, 6, 5, 4, 3, 2, 1]`。

---

### ✅ 答案解析

**题1 答案：B**

切片语法 `[start:stop:step]`：
- `start=1` → 从索引1开始（元素20）
- `stop=4` → 到索引4结束，但不包含索引4（即只取到索引3的元素40）
- `step=2` → 每隔2步取一个

所以取的顺序是：索引1（20）→ 索引3（40），结果是 `[20, 40]`。

**题2 答案：**
```python
data[::-1]
```

解释：省略 start 和 stop，step 设为 -1，Python 会从末尾向开头遍历，实现反转。这是 Python 中最简洁优雅的反转写法。
