**知识点：条件判断与逻辑运算符的混合使用**

很多时候，判断一个条件不是单一的“是”或“否”，而是需要“并且”、“或者”这样的逻辑组合。

**题目：**

假设你要写一个判断用户是否能享受“周末会员折扣”的程序。规则是：
- 必须是周末（`is_weekend = True` 表示是周末）
- **并且** 用户必须是会员（`is_member = True` 表示是会员）

请判断以下哪段代码能正确输出“享受折扣”？（单选题）

A.
```python
if is_weekend or is_member:
    print("享受折扣")
```

B.
```python
if is_weekend and is_member:
    print("享受折扣")
```

C.
```python
if is_weekend == is_member:
    print("享受折扣")
```

---

**答案解析：**

答案是 **B**。

- **A选项** 使用了 `or`（逻辑或），意思是“只要满足一个就行”。如果是周末但不是会员，或者不是周末但是会员，它都会输出“享受折扣”，这不符合题目要求。
- **B选项** 使用了 `and`（逻辑与），意思是“必须两个都满足”。只有当 `is_weekend` 和 `is_member` 同时为 `True` 时，条件才成立，这完全符合“周末 **并且** 会员”的规则。
- **C选项** 比较的是两个变量的值是否相等。如果 `is_weekend` 和 `is_member` 都是 `False`，`False == False` 也是 `True`，这会产生完全错误的判断逻辑。

**一句话总结：** `and` 是“都要”，`or` 是“只要”。
