**知识点**：可变与不可变数据类型（Mutable vs Immutable）

---

**题目1（选择题）**  
以下哪个操作会**改变**原对象？

A. `a = [1, 2, 3]; a.append(4)`  
B. `b = "hello"; b.upper()`  
C. `c = (1, 2, 3); c + (4,)`  
D. `d = 5; d = d + 1`

---

**题目2（简答题）**  
请说出 Python 中 **列表（list）** 和 **字符串（str）** 在内存管理上的一个关键区别，并解释为什么这个区别重要。

---

**答案解析**：

**题目1：A**  
- A ✅：列表是可变类型，`append()` 直接在原列表上添加元素，原对象被改变。  
- B ❌：`upper()` 返回一个新字符串，原字符串不变（字符串不可变）。  
- C ❌：`+` 创建了一个新的元组，原元组不变（元组不可变）。  
- D ❌：`d = d + 1` 创建了一个新的整数对象，原整数不变（整数不可变）。

**题目2**：  
列表是 **可变** 的——你可以在不改变内存地址的情况下修改其内容（如增删改元素）。  
字符串是 **不可变** 的——任何修改操作都会创建一个新的字符串对象，原字符串的内存地址不变且内容不变。  

这个区别很重要，因为它影响：
- **性能**：频繁修改字符串会产生大量临时对象，效率低；而列表修改更高效。
- **安全性**：不可变对象可以作为字典的键，而列表不行。
- **并发**：不可变对象天然线程安全。
