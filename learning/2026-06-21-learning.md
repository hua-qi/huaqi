**知识点：** `if-elif-else` 条件判断与逻辑运算符 (`and`, `or`, `not`)

**题目 1（选择题）：**  
以下代码的输出是什么？
```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("允许进入")
elif age >= 18 and not has_ticket:
    print("请购票")
else:
    print("未成年禁止入内")
```
A. 允许进入  
B. 请购票  
C. 未成年禁止入内  

**题目 2（简答题）：**  
请用 `if-elif-else` 写一段代码：  
如果温度 `temp` 大于 30，打印“太热了”；如果温度在 20 到 30 之间（含两端），打印“舒适”；否则打印“有点凉”。

---

**答案解析：**

**题目 1 答案：A**  
`age` 是 25（>=18 为 True），`has_ticket` 是 True，所以 `age >= 18 and has_ticket` 是 `True and True`，结果为 `True`，进入第一个分支，打印“允许进入”。

**题目 2 示例答案：**
```python
temp = 25
if temp > 30:
    print("太热了")
elif 20 <= temp <= 30:
    print("舒适")
else:
    print("有点凉")
```
注意：Python 支持链式比较 `20 <= temp <= 30`，比写 `temp >= 20 and temp <= 30` 更简洁。
