### 📝 题目1（选择题）

以下代码的输出是什么？

```python
x = 5
y = 10
z = 0

result = x > 3 and y < 15 or not z
print(result)
```

A. `True`  
B. `False`  
C. `5`  
D. 会报错

### 📝 题目2（简答题）

请用 `if-elif-else` 写一段代码：  
输入一个学生的分数（0-100），判断等级：
- 90分及以上：`"优秀"`
- 60分（含）到89分：`"及格"`
- 60分以下：`"不及格"`

如果分数不在0-100范围内，输出 `"无效分数"`。

---

### ✅ 答案解析

**第1题：**

正确答案是 **A. `True`**。

运算顺序解析（运算符优先级：`not` > `and` > `or`）：
1. `not z` → `not 0` → `True`
2. `x > 3` → `5 > 3` → `True`
3. `y < 15` → `10 < 15` → `True`
4. 原式变成：`True and True or True`
5. `True and True` → `True`
6. `True or True` → `True`（短路求值，左边已经是True，右边不再计算）

**第2题：**

参考代码：

```python
score = int(input("请输入分数："))

if score < 0 or score > 100:
    print("无效分数")
elif score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

注意点：
- 先判断边界条件（无效分数），避免后续逻辑出错
- `elif` 的顺序很重要，从高到低或从低到高，但一旦匹配就跳出整个结构
- 最后一个 `else` 隐含了 `score < 60` 且有效的条件
