**知识点：条件判断与布尔逻辑**

**第一题（选择题）：**
以下代码的输出是什么？
```python
x = 10
if x > 5 and x < 15:
    print("A")
elif x > 8 or x < 3:
    print("B")
else:
    print("C")
```
A. A
B. B
C. C
D. 报错

**第二题（简答题）：**
请用一句话解释，为什么在 Python 中 `if 0:` 这个条件判断的结果是“假”（不会执行 if 内部的代码）？

---

**✅ 答案解析：**

**第一题答案：A**
**解析：** 程序会按顺序检查条件。
1. 第一个 `if` 判断 `x > 5 and x < 15`。因为 `x = 10`，所以 `10 > 5` 为真，`10 < 15` 也为真，`True and True` 的结果是 `True`。因此直接打印 "A"，**后面的 `elif` 和 `else` 都不会被执行**。这是 `if-elif-else` 结构的特点：一旦找到满足的条件，就跳出整个判断结构。

**第二题参考解析：**
因为在 Python 中，数字 `0` 在布尔上下文中被视为 `False`（假值）。同理，空字符串 `""`、空列表 `[]` 等也会被视为假。所以 `if 0:` 等价于 `if False:`，条件不成立，代码块不会执行。这体现了 Python 的“真值测试”机制——除了显式的 `False` 和 `None`，一些“空”或“零”的值也会被隐式转换为假。
