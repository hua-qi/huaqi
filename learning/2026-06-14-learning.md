**题目 1（选择题）**  
以下代码的输出是什么？
```python
x = 5
if x > 10:
    print("A")
elif x > 3:
    print("B")
else:
    print("C")
```
A. A  
B. B  
C. C  
D. 报错

**题目 2（简答题）**  
请写一段代码：  
定义变量 `age = 18`，如果 age 大于等于 18，打印 "成年人"；否则打印 "未成年人"。  
（提示：使用 `if-else`）

---

**答案解析**  
- **第1题**：选 **B**。`x = 5` 不满足 `x > 10`，但满足 `x > 3`，所以执行 `print("B")`，输出 B。  
- **第2题**：参考代码如下：
  ```python
  age = 18
  if age >= 18:
      print("成年人")
  else:
      print("未成年人")
  ```
  注意 `>=` 是“大于等于”，别忘了冒号 `:` 和缩进。
