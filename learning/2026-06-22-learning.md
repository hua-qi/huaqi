**知识点：可变与不可变数据类型**

在Python中，数据类型分为**可变**（mutable）和**不可变**（immutable）两类。这直接影响你如何操作数据，也是很多新手容易踩坑的地方。

---

**题目1（选择题）：**
以下哪个操作会**改变**原对象？

A. `a = [1, 2, 3]; a.append(4)`
B. `b = "hello"; b.upper()`
C. `c = (1, 2, 3); c[0] = 0`
D. `d = {1, 2, 3}; d.add(4)`

**题目2（简答题）：**
请解释为什么下面的代码中，`x` 和 `y` 的值不同？

```python
x = 10
y = x
x = x + 5
print(x)  # 15
print(y)  # 10
```

---

**答案解析：**

**题目1：正确答案是 A 和 D**
- A 中的列表是**可变**类型，`append` 直接在原列表上修改
- B 中的字符串是**不可变**类型，`upper()` 返回一个新字符串，原字符串不变
- C 中的元组是**不可变**类型，不能修改元素（会报错）
- D 中的集合是**可变**类型，`add` 直接修改原集合

**题目2：**
整数是**不可变**类型。`x = 10` 创建一个整数对象 10，`y = x` 让 y 指向同一个对象。当执行 `x = x + 5` 时，Python 会创建一个**新的整数对象 15**，并让 x 指向它，而 y 仍然指向原来的 10。所以 x 和 y 最终指向不同的对象。
