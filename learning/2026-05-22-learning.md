**题目 1（选择题）**：
以下代码的输出是什么？
```python
numbers = [1, 2, 3, 4, 5]
result = []
for num in numbers:
    if num % 2 == 0:
        result.append(num * 2)
print(result)
```
A. [2, 4, 6, 8, 10]  
B. [4, 8]  
C. [2, 6, 10]  
D. [2, 4, 8]

**题目 2（简答题）**：
请用一行列表推导式（list comprehension）重写上面的代码，实现相同的功能：从列表 `[1, 2, 3, 4, 5]` 中筛选出偶数，并将每个偶数乘以 2。

---

**答案解析**：
- **题目 1 答案：B**  
  循环遍历每个数字，`num % 2 == 0` 只对偶数（2 和 4）成立，然后分别乘以 2 得到 4 和 8。其他选项要么漏掉了条件，要么乘错了数。

- **题目 2 答案**：  
  ```python
  result = [num * 2 for num in [1, 2, 3, 4, 5] if num % 2 == 0]
  ```
  列表推导式的结构是 `[表达式 for 变量 in 可迭代对象 if 条件]`，这里把循环和条件判断压缩成了一行，既简洁又高效。
