### 题目 1（选择题）
下面这段代码的输出是什么？
```python
x = 10
if x > 5 and x < 15:
    print("A")
elif x == 10 or x > 20:
    print("B")
else:
    print("C")
```
A. A  
B. B  
C. C  
D. 会报错

### 题目 2（简答题）
请写一段代码：如果 `score` 大于等于 90，打印"优秀"；如果大于等于 75 但小于 90，打印"良好"；否则打印"继续努力"。要求使用 `if-elif-else` 结构。

---

### 答案解析

**题目 1 答案：A**  
- `x > 5` 为 True，`x < 15` 也为 True，所以 `x > 5 and x < 15` 整体为 True  
- 直接执行第一个 `if` 分支，输出 "A"  
- 注意：`elif` 和 `else` 都不会被执行，因为条件已经满足

**题目 2 参考代码：**
```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 75:
    print("良好")
else:
    print("继续努力")
```
关键点：`elif` 的顺序很重要——先判断最严格的条件（>=90），再放宽条件（>=75），这样逻辑才正确。
