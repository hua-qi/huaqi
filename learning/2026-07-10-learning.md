### 题目 1（选择题）

以下代码的输出是什么？

```python
a = 0
b = "0"
if a:
    print("a 为真")
elif b:
    print("b 为真")
else:
    print("两者都为假")
```

A. `a 为真`
B. `b 为真`
C. `两者都为假`

### 题目 2（简答题）

请用一句话解释：为什么在 Python 中，`0` 和 `"0"` 在 `if` 语句中的表现不同？

---

### 答案解析

**题目 1 答案：B**

- `a = 0`，整数 0 在 Python 中会被当作 `False`（假值），所以第一个条件不成立。
- `b = "0"`，这是一个**非空字符串**，非空字符串在 Python 中会被当作 `True`（真值），所以 `elif b` 成立，输出 `b 为真`。

**题目 2 解析：**

因为 Python 判断真假时，**不同数据类型有自己的“假值”规则**。
- 整型：`0` 是假，其他整数（包括负数）是真。
- 字符串：**空字符串 `""`** 是假，**任何非空字符串**（哪怕是 `"0"`、`"False"`）都是真。

这背后是 Python 的 **“真值测试”** 机制：每个对象本质上都有一个 `__bool__()` 或 `__len__()` 方法，决定它在条件语句中是 True 还是 False。
