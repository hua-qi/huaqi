**知识点：条件判断与逻辑运算符的组合使用**

在Python中，`and`、`or`、`not` 这三个逻辑运算符可以组合出非常灵活的条件判断。尤其是 `and` 和 `or` 的短路特性——`and` 遇到第一个 `False` 就停，`or` 遇到第一个 `True` 就停。

---

### 题目1（选择题）

下面这段代码的输出是什么？

```python
x = 5
y = 0
result = x > 3 and y != 0 or x == 5
print(result)
```

A. `True`  
B. `False`  
C. `5`  
D. `0`

---

### 题目2（简答题）

请解释为什么下面这个条件判断永远不会进入 `if` 分支，并修改它使其能正确判断“年龄在18到60岁之间（含两端）”：

```python
age = 25
if 18 <= age <= 60:
    print("符合条件")
```

---

### 答案解析

**题目1 答案：A. True**

解析：
1. 先算 `x > 3` → `True`
2. `True and (y != 0)` → `y != 0` 是 `False`，但 `and` 需要两边都 `True`，所以这一步结果是 `False`
3. 然后 `False or (x == 5)` → `x == 5` 是 `True`，所以最终结果是 `True`

**题目2 答案：**

题目给出的代码其实**是正确的**！Python支持链式比较，`18 <= age <= 60` 等价于 `age >= 18 and age <= 60`。

但如果你想让代码更清晰，或者需要更复杂的逻辑，可以写成：
```python
if age >= 18 and age <= 60:
    print("符合条件")
```

所以这道题其实是**陷阱题**——让你意识到Python的链式比较是一个很优雅的特性，但很多人会误以为它不工作。
