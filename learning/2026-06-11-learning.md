**课程：Python基础语法与数据类型**  
**知识点：列表（list）的常用方法与可变性**

### 题目1（简答）
以下代码执行后，`my_list` 的值是什么？请解释原因。
```python
my_list = [1, 2, 3]
new_list = my_list
new_list.append(4)
print(my_list)
```

### 题目2（选择）
如果你想要创建一个 `my_list` 的**独立副本**，修改副本不影响原列表，应该使用哪种方式？
A. `new_list = my_list`  
B. `new_list = my_list.copy()`  
C. `new_list = list(my_list)`  
D. `new_list = my_list[:]`

---

### 答案解析

**题目1**：`[1, 2, 3, 4]`  
因为 `new_list = my_list` 只是创建了一个**引用**，两个变量指向同一个列表对象。列表是**可变类型**，所以修改 `new_list` 也会影响 `my_list`。

**题目2**：B、C、D 都正确  
- A ❌：只是创建引用，不是独立副本  
- B ✅：`copy()` 方法创建浅拷贝  
- C ✅：`list()` 构造函数创建新列表  
- D ✅：切片操作 `[:]` 创建新列表  

**关键洞察**：理解"可变 vs 不可变"和"引用 vs 副本"是Python进阶的基石。很多bug就藏在这些看似微小的区别里。
