### 题目

**选择题**：以下代码的输出是什么？

```python
x = 8
if x > 5 and x % 2 == 0:
    print("A")
elif x > 3 or x < 10:
    print("B")
else:
    print("C")
```

A. A  
B. B  
C. C  
D. 语法错误

---

### 答案解析

**正确答案：A**

**解析**：  
- 第一个条件 `x > 5 and x % 2 == 0`：`8 > 5` 为 True，`8 % 2 == 0` 也为 True，`and` 两边都成立，整体为 True。  
- 一旦第一个 `if` 条件成立，Python 就不会再去检查 `elif` 和 `else` 了。所以直接输出 **A**。

这里有个容易踩的坑：`elif` 里的 `or` 条件（`x > 3 or x < 10`）实际上也是 True，但**它根本不会被执行到**——因为 `if` 已经命中了。这提醒我们：**条件判断的顺序很重要，先命中的分支会“吃掉”后面的机会**。
