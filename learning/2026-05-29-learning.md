### 题目 2（简答题）：
请用 `if-elif-else` 写一段代码，判断一个整数 `score` 的等级：
- 90 分及以上：A  
- 80-89 分：B  
- 70-79 分：C  
- 60-69 分：D  
- 60 分以下：E

（假设 `score` 已定义，只需写出判断逻辑）

---

### 答案解析

**题目 1 解析：**  
答案是 **B. False**。  
我们来拆解运算顺序（逻辑运算优先级：`not` > `and` > `or`）：
1. `x > 3` → `5 > 3` → `True`
2. `y < 15` → `10 < 15` → `True`
3. `not x == 5` → `not True` → `False`
4. 所以：`True and True or False` → `True or False` → `True`
等等，我算出来是 True？让我再检查一下——  
实际上 `True and True` 是 `True`，然后 `True or False` 是 `True`。  
但等等，`not` 的优先级更高，`x == 5` 是 `True`，所以 `not True` 是 `False`。  
然后 `True and True` 是 `True`，最后 `True or False` 是 `True`。  
所以答案是 **A. True**。抱歉刚才绕了一下！😅 正确答案是 A。

**题目 2 解析（参考代码）：**
```python
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
elif score >= 70:
    grade = 'C'
elif score >= 60:
    grade = 'D'
else:
    grade = 'E'
```
关键点：`elif` 的顺序很重要，从高到低判断，避免重叠条件。
