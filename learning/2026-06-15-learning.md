**题目 1（选择题）：**
假设有一个变量 `score = 85`，你想根据以下规则输出等级：
- 90 分及以上：A
- 80 分（含）到 90 分：B
- 70 分（含）到 80 分：C
- 70 分以下：D

以下哪个 `if-elif-else` 结构**逻辑正确**且能输出 `B`？

A.
```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

B.
```python
if score < 70:
    print("D")
elif score < 80:
    print("C")
elif score < 90:
    print("B")
else:
    print("A")
```

C. 两个都正确
D. 两个都错误

**题目 2（简答题）：**
请用**一行代码**（使用逻辑运算符 `and` 或 `or`）判断一个整数 `num` 是否**不在**区间 [10, 20] 内（即小于10或大于20），并将结果赋值给变量 `outside`。

例如：
- 如果 `num = 5`，则 `outside` 应为 `True`
- 如果 `num = 15`，则 `outside` 应为 `False`

---

**答案解析：**

**题目 1 答案：C（两个都正确）**

两个结构都正确，但体现了两种不同的思维习惯：
- **A 方案**：从上往下“排除”高分，逻辑直观，是大多数人的第一反应。
- **B 方案**：从上往下“排除”低分，逻辑同样严密，但容易让人误以为 `elif` 是“范围判断”而非“顺序排除”。只要理解 `elif` 的“一旦匹配就跳过剩余”机制，B 方案在性能上其实和 A 一样高效。

**题目 2 答案：**
```python
outside = num < 10 or num > 20
```
或者：
```python
outside = not (10 <= num <= 20)
```
（Python 支持链式比较，非常优雅）

**关键点**：要小心“不在区间内”的边界条件。区间 [10, 20] 包含 10 和 20，所以“不在”就是 `num < 10` 或 `num > 20`。
