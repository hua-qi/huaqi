**题目：**

假设你要写一个小程序，判断用户输入的一个年份是否为闰年。闰年的规则是：能被4整除但不能被100整除，或者能被400整除。

请用Python代码实现这个判断逻辑，并输出“是闰年”或“不是闰年”。

（提示：你可以假设用户输入的是一个整数，用 `int()` 转换；整除操作用 `%` 运算符。）

**解析：**

这道题考验的是你对**数据类型转换**（`int()`）、**逻辑运算符**（`and`、`or`）以及**条件语句**（`if/else`）的综合运用。

一个标准的实现如下：

```python
year = int(input("请输入一个年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")
```

- `int(input(...))` 将用户输入的字符串转为整数。
- `year % 4 == 0` 判断是否能被4整除。
- `year % 100 != 0` 判断是否能被100整除（取反）。
- `year % 400 == 0` 判断是否能被400整除。
- 通过 `and` 和 `or` 组合条件，完美匹配闰年规则。
