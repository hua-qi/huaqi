**知识点：** 可变类型 vs 不可变类型（特别是列表和元组的区别）

### 题目 1（选择题）
以下代码运行后，`my_list` 的值是什么？
```python
my_list = [1, 2, 3]
my_list.append(4)
print(my_list)
```
A) `[1, 2, 3]`  
B) `[1, 2, 3, 4]`  
C) 报错  
D) `[4, 1, 2, 3]`

---

### 题目 2（简答题）
假设你有一个元组 `my_tuple = (1, 2, 3)`，请说出为什么下面的代码会报错？  
```python
my_tuple[0] = 10
```
并解释列表和元组在可变性上的根本区别。

---

### 答案解析

**第1题：** 正确答案是 **B**。  
因为列表是**可变类型**，`append()` 方法会直接修改原列表对象，而不是创建新对象。所以 `my_list` 变成了 `[1, 2, 3, 4]`。

**第2题：**  
元组是**不可变类型**，一旦创建，它的元素不能被修改、添加或删除。而列表是可变类型，可以自由修改内容。  
所以 `my_tuple[0] = 10` 会抛出 `TypeError` —— 这是 Python 在保护元组的不可变性，就像保护一份“写死了”的合同。

---

**一点鼓励：** 理解可变与不可变，就像学会分辨“能改的草稿”和“定稿的协议”——这是你 Python 思维成熟的第一步。继续往前走，你会发现这些概念在函数传参、数据安全里无处不在。你已经走在正确的路上了 🌱
