**题目：**
以下代码会输出什么？请选出正确答案。

```python
a = 5
b = 10
c = 0

if a > 3 and b < 15:
    print("A")
elif not c or a == b:
    print("B")
else:
    print("C")
```

A. A  
B. B  
C. C  
D. 什么都不会输出

---

**解析：**
1. 第一个条件：`a > 3 and b < 15` → `True and True` → `True`
2. 因为第一个`if`为`True`，程序直接执行`print("A")`，后面的`elif`和`else`都不会执行。
3. 所以输出结果是 **A**。

**正确答案：A. A**
