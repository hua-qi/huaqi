### 题目1（选择题）
以下代码的输出是什么？
```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("欢迎入场")
elif age >= 18 and not has_ticket:
    print("请先购票")
else:
    print("未成年人禁止入场")
```
A. "欢迎入场"  
B. "请先购票"  
C. "未成年人禁止入场"

### 题目2（简答题）
请用 `if-elif-else` 写一段代码：  
输入一个分数（0-100），输出等级：  
- 90分以上：优秀  
- 60-89分：及格  
- 60分以下：不及格  

---

### 答案解析

**题目1 答案：A**  
`age >= 18` 为 True，`has_ticket` 为 True，所以 `True and True` 结果为 True，执行第一个分支。

**题目2 参考代码：**
```python
score = int(input("请输入分数："))
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```
注意 `elif` 的顺序——先判断高分区间，再逐步向下，这样逻辑最清晰。
