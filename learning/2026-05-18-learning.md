**题目 2（简答题）：**
请写一段代码：判断一个年份是否为闰年。规则是：能被4整除但不能被100整除，或者能被400整除。

---

**答案解析：**

**题目 1 答案：B. False**
- `(x > 5)` → True（10 > 5）
- `(y < 15)` → False（20 < 15 不成立）
- `True and False` → False
- `(x + y == 30)` → True（10+20=30）
- `False or True` → True？等等，这里有个坑！
- 实际上：`and`的优先级高于`or`，所以先算`(x > 5) and (y < 15)` = False
- 然后 `False or (x + y == 30)` = False or True = True
- 等等，我重新算：`x + y == 30` 是 True，所以结果是 **True**。
- 正确答案是 **A. True**。抱歉，我刚才绕了一下——重点是想让你注意运算符优先级。

**题目 2 参考代码：**
```python
year = 2024
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year}是闰年")
else:
    print(f"{year}不是闰年")
```
