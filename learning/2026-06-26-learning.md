### 题目 1（选择题）

以下代码的输出是什么？
```python
for i in range(5):
    if i % 2 == 0:
        print(f"{i}是偶数")
    else:
        print(f"{i}是奇数")
```
A. 输出 0 到 4 中所有偶数和奇数  
B. 只输出奇数  
C. 只输出偶数  
D. 报错，因为 `range(5)` 不包含 5  

### 题目 2（简答题）

请用 `for` 循环和 `if` 语句，写一段代码：  
**打印 1 到 10 中所有能被 3 整除的数字。**

---

### 答案解析

**题目 1 答案：A**

`range(5)` 生成的是 `[0, 1, 2, 3, 4]`，循环会遍历每一个数。  
- `i % 2 == 0` 判断是否为偶数（0 也是偶数哦！）  
- 所以会依次判断并输出：0是偶数、1是奇数、2是偶数、3是奇数、4是偶数  
- 因此 A 正确，B 和 C 都只说了部分，D 错在 range(5) 确实生成 0-4，不会报错。

**题目 2 参考代码：**
```python
for num in range(1, 11):  # 注意这里是 1 到 10
    if num % 3 == 0:
        print(num)
```
输出：`3 6 9`  
关键点：`range(1, 11)` 生成 1 到 10，`num % 3 == 0` 判断是否能被 3 整除。
