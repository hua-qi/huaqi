**题目1（选择题）：**
以下哪个代码片段可以正确地将字符串 "apple" 添加到列表 fruits 的末尾？
A. fruits = fruits + "apple"
B. fruits.append("apple")
C. fruits.add("apple")
D. fruits.push("apple")

**题目2（简答题）：**
请写出一段代码，创建一个包含3个学生姓名和对应年龄的字典，然后打印出年龄最大的学生名字。

---

**答案解析：**

**题目1 答案：B**
- A 错误，因为列表不能直接用 + 连接字符串，会报 TypeError
- B 正确，`append()` 是列表的标准方法，用于在末尾添加元素
- C 错误，`add()` 是集合（set）的方法，不是列表的
- D 错误，`push()` 是 JavaScript 数组的方法，Python 列表没有这个方法

**题目2 参考代码：**
```python
students = {"小明": 18, "小红": 20, "小刚": 19}
max_age = max(students.values())
for name, age in students.items():
    if age == max_age:
        print(name)  # 输出：小红
```
