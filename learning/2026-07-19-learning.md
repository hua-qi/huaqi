**题目1（简答）**  
看这段代码，说出输出结果，并解释为什么：

```python
x = 5
y = 10
if x > 3 and y < 8:
    print("条件A")
elif not (x == 5):
    print("条件B")
else:
    print("条件C")
```

**题目2（选择）**  
假设你想让程序在 `age` 大于等于 18 且 `has_id` 为 True 时允许进入，否则拒绝。下面哪个写法最准确？

A. `if age >= 18 or has_id == True:`
B. `if age >= 18 and has_id:`
C. `if age > 18 and has_id == True:`
D. `if age >= 18 and has_id == "True":`

---

**答案解析**

**题1答案：** 输出 `条件C`。  
- 第一个 `if`：`x > 3` 为 True，但 `y < 8` 为 False（y=10），所以整体 `and` 为 False  
- 第二个 `elif`：`not (x == 5)` → `not True` → False  
- 两个条件都没满足，走 `else`

**题2答案：** B  
- `and` 表示两个条件都必须成立，符合“且”的逻辑  
- `has_id` 本身就是布尔值，不需要写 `== True`（这是新手常见冗余）  
- A 用了 `or`，只要满足一个就放行，太宽松  
- C 漏掉了 `age == 18` 的情况（18岁正好成年）  
- D 把布尔值和字符串 `"True"` 比较，永远不会相等
