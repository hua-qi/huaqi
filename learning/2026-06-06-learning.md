**课程：Python基础语法与数据类型**

**知识点：可变 vs 不可变数据类型**

---

**题目1（选择题）：**
以下哪个变量的值在创建后是无法被修改的？
A) list_a = [1, 2, 3]
B) dict_b = {"name": "Alice"}
C) str_c = "Hello"
D) set_d = {1, 2, 3}

---

**题目2（简答题）：**
请解释为什么下面这段代码会报错，并说明如何修正：
```python
text = "Python"
text[0] = "p"
```

---

**解析：**

**题目1答案：C**
字符串（str）是不可变类型。A、B、D分别是列表、字典、集合，都是可变类型。你可以修改列表的元素、添加字典的键值对、增减集合的元素，但字符串一旦创建，里面的字符就不能被单独修改。

**题目2解析：**
因为字符串是不可变类型。`text[0] = "p"` 尝试修改字符串的第一个字符，这违反了不可变原则，会引发 `TypeError`。正确的做法是重新创建一个新字符串：
```python
text = "Python"
text = "p" + text[1:]  # 输出 "python"
```
或者使用 `replace()` 方法：
```python
text = "Python"
text = text.replace("P", "p")  # 输出 "python"
```
