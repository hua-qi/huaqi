## 题目

**1.（选择题）** 在Python中，执行以下代码后，`result` 的值是什么？

```python
a = 0
b = 5
result = a and b
```

A. `0`  
B. `5`  
C. `True`  
D. `False`

**2.（简答题）** 请解释为什么下面的代码不会引发 `ZeroDivisionError`：

```python
x = 0
y = 10 / x if x != 0 else 0
```

---

## 答案解析

**第1题答案：A. `0`**

**解析：** 在Python中，`and` 运算符会进行**短路求值**。当 `a = 0`（在布尔上下文中为 `False`）时，`and` 运算符已经确定整个表达式的结果为 `False`，因此它**不会继续计算** `b` 的值，而是直接返回 `a` 的值（即 `0`）。  
如果 `a` 为真（如 `a = 3`），则会继续计算 `b`，并返回 `b` 的值（`5`）。

**第2题答案：** 代码使用了条件表达式（三元运算符），当 `x != 0` 为 `False` 时，直接执行 `else 0`，因此 `y` 被赋值为 `0`，不会执行 `10 / x` 这条可能引发除零错误的语句。这本质上也是**短路求值**思想的一种体现——只在必要时才计算表达式。
