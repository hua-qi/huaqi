**知识点：** 逻辑运算的短路求值（Short-circuit Evaluation）

---

**题目（简答+代码）：**

看下面这段代码，猜猜打印结果是什么，并解释为什么：

```python
def check():
    print("check 被调用了")
    return True

result = False and check()
print(result)
```

---

**答案解析：**

打印结果是：

```
False
```

（注意：**不会**打印 "check 被调用了"）

**原因：** Python 的逻辑运算遵循短路求值。`and` 运算符在左侧为 `False` 时，已经能确定整个表达式的结果为 `False`，就不再计算右侧的 `check()` 函数。所以 `check()` 根本不会被调用。

这个特性在后续写 React 的条件渲染（比如 `{isLogin && <UserPanel />}`）时非常关键——你依赖的正是这种"左侧为假就跳过右侧"的机制。
