**题目1（选择题）：**
以下代码的输出是什么？
```python
x = 5
y = 10
z = 15

result = x > 3 and y < 12 or not z == 15
print(result)
```
A) True  
B) False  
C) 语法错误  
D) 不确定

**题目2（简答题）：**
请用一句话解释：为什么在 Python 中，`if 3 < x < 10` 这种写法是合法的，而在其他一些语言中需要写成 `if x > 3 and x < 10`？

---

**答案解析：**

**题目1 解析：**
答案是 **B) False**

一步步拆解：
1. `x > 3` → `5 > 3` → `True`
2. `y < 12` → `10 < 12` → `True`
3. `True and True` → `True`
4. `not z == 15` → `not True` → `False`
5. `True or False` → `True`

等等，我算出来是 True？让我再检查一下……

哦，我犯了一个常见的错误！**`not` 的优先级高于 `or`**，所以实际上是：
- `not z == 15` → `not True` → `False`
- `x > 3 and y < 12` → `True and True` → `True`
- `True or False` → **True**

正确答案是 **A) True**！

**题目2 解析：**
Python 支持链式比较（chained comparison），这是一种语法糖。`3 < x < 10` 实际上被解释为 `(3 < x) and (x < 10)`，中间只计算一次 x。这让代码更简洁、更接近数学表达式的自然写法。
