## 📝 复习题

**题目1（选择题）：**
以下 Python 代码的输出是什么？
```python
x = 5
if x > 3 and x < 10 or x == 0:
    print("条件成立")
else:
    print("条件不成立")
```
A. 条件成立  
B. 条件不成立  
C. 语法错误  
D. 无法确定

**题目2（简答题）：**
请用逻辑运算符 `and` 和 `or`，写一个条件表达式，判断一个整数 `num` 是否**既不是负数，也不是大于 100 的数**（即 num 在 0 到 100 之间，包含边界）。

---

## 🔍 答案解析

**题目1 解析：**
答案是 **A. 条件成立**。

关键点在于 **运算符优先级**：`and` 的优先级高于 `or`，所以表达式实际被解析为：
```python
(x > 3 and x < 10) or (x == 0)
```
- `x > 3 and x < 10` → 5 在 3 和 10 之间 → `True`
- `x == 0` → `False`
- `True or False` → `True`

很多新手会误以为是从左到右依次求值，导致判断错误。记住：**`and` 先结婚，`or` 后办酒** 😄

**题目2 参考答案：**
```python
num >= 0 and num <= 100
```
或者更 Pythonic 的写法：
```python
0 <= num <= 100
```
这个写法利用了 Python 的链式比较，但在理解逻辑时，本质上还是 `and` 的关系。
