**课程**：Python基础  
**知识点**：条件判断与逻辑运算符（`and`、`or`、`not`）的短路求值

**题目1（选择题）**  
以下代码的输出是什么？
```python
x = 5
y = 0
result = x > 3 and (y / x) > 0
print(result)
```
A. `True`  
B. `False`  
C. `ZeroDivisionError`  
D. `None`

**题目2（简答题）**  
请用一句话解释：为什么下面的代码不会报错，而直接返回 `False`？
```python
a = 0
b = 10
result = a != 0 and (b / a) > 1
```

---

**答案解析**

**题目1 答案：B. `False`**  
解析：  
- `x > 3` 为 `True`，所以继续计算 `(y / x) > 0`  
- `y / x = 0 / 5 = 0`，`0 > 0` 为 `False`  
- 最终结果是 `False`

**题目2 答案：**  
因为 `and` 运算符遵循**短路求值**规则——当第一个条件 `a != 0` 为 `False` 时，整个 `and` 表达式已经确定为 `False`，Python 不会再计算后面的 `(b / a) > 1`，所以避免了除零错误。
