### 📚 知识点：可变 vs 不可变数据类型

**题目：**
以下代码运行后，`my_list` 的值是什么？

```python
my_list = [1, 2, 3]
my_string = "hello"

my_list.append(4)
my_string.upper()

print(my_list)
print(my_string)
```

A) `[1, 2, 3, 4]` 和 `"HELLO"`
B) `[1, 2, 3, 4]` 和 `"hello"`
C) `[1, 2, 3]` 和 `"HELLO"`
D) `[1, 2, 3]` 和 `"hello"`

---

**简答题（选做）：**
为什么字符串调用 `.upper()` 后原变量不变，而列表调用 `.append()` 却改变了原变量？这背后体现了Python的什么核心概念？

---

### 🔍 答案解析

**选择题答案：B**

`my_list.append(4)` 修改了原列表对象，所以 `my_list` 变成了 `[1, 2, 3, 4]`。

而 `my_string.upper()` 返回的是**新字符串** `"HELLO"`，但原变量 `my_string` 仍然指向 `"hello"`——除非你重新赋值：`my_string = my_string.upper()`。

**简答题核心：**
这体现了 **可变（mutable）与不可变（immutable）数据类型** 的区别：
- **列表是可变类型**：方法直接修改原对象
- **字符串是不可变类型**：任何"修改"操作都会创建新对象，原对象不变

其他常见不可变类型：`int`、`float`、`tuple`、`str`
常见可变类型：`list`、`dict`、`set`
