### 📚 知识点：可变 vs. 不可变数据类型

在 Python 里，数据对象分为两类：
- **不可变类型**：创建后内容不可修改。包括：`int`, `float`, `str`, `tuple`。
- **可变类型**：创建后内容可以修改。包括：`list`, `dict`, `set`。

理解这个区别，对后面学函数、参数传递、内存管理都至关重要。

### 🧠 复习题

**题目 1（选择题）：**
以下哪个操作会**改变**原始对象本身？

A. `a = "hello"; a.upper()`
B. `b = [1, 2, 3]; b.append(4)`
C. `c = (1, 2, 3); c + (4,)`
D. `d = 5; d + 1`

---

**题目 2（简答题）：**
请解释为什么下面的代码会报错，并说明如何修改让它正确运行：

```python
my_tuple = (1, 2, [3, 4])
my_tuple[2] = [5, 6]  # 报错
```

---

### ✅ 答案解析

**题目 1 答案：B**

- A：`str.upper()` 返回一个新字符串，原字符串 `a` 不变（字符串不可变）
- B：`list.append()` 直接在原列表末尾添加元素，`b` 被修改（列表可变）
- C：`+` 操作创建新元组，原元组 `c` 不变（元组不可变）
- D：`+` 创建新整数，原 `d` 不变（整数不可变）

**题目 2 解析：**
报错原因：元组 `my_tuple` 本身是**不可变**的，所以不能直接修改其元素 `my_tuple[2] = ...`。

但注意！元组里的第三个元素**本身是一个列表**（可变对象）。所以可以这样改：

```python
my_tuple = (1, 2, [3, 4])
my_tuple[2].append(5)
my_tuple[2][0] = 99
print(my_tuple)  # (1, 2, [99, 4, 5])
```

这里我们没有修改元组本身，而是修改了元组内部那个列表的内容——这是允许的。
