**📚 课程：Python 基础语法与数据类型**
**🎯 知识点：可变对象 vs 不可变对象（以列表和字符串为例）**

在 Python 里，数据类型分为可变和不可变，这直接影响你对数据的操作行为，是后面理解函数、内存管理的基础。

---

**📝 题目 1（选择题）**
执行以下代码后，`a` 和 `b` 的值分别是什么？
```python
a = [1, 2, 3]
b = a
b.append(4)
```
A. a=[1,2,3], b=[1,2,3,4]  
B. a=[1,2,3,4], b=[1,2,3,4]  
C. a=[1,2,3], b=[1,2,3]  
D. 报错

**📝 题目 2（简答题）**
如果把上面的列表换成字符串，执行以下代码，`c` 的值会改变吗？为什么？
```python
c = "hello"
d = c
d = d + " world"
```

---

**🔍 答案解析**

**题目 1 答案：B**
**解析：** 列表是**可变对象**。`b = a` 并没有复制列表，而是让 `b` 和 `a` 指向了**同一个**内存地址。当你通过 `b.append(4)` 修改这个列表时，`a` 指向的也是同一个列表，所以 `a` 也会改变。这就好比你和朋友共享一个笔记本，朋友在笔记本上写了东西，你打开看当然也有。

**题目 2 答案：不会改变。**
**解析：** 字符串是**不可变对象**。`d = c` 同样让 `d` 指向了 `c` 的内容。但执行 `d = d + " world"` 时，Python 并不是修改原来的字符串 "hello"，而是**创建了一个全新的字符串 "hello world"**，并让 `d` 指向这个新字符串。原来的 `c` 依然指向 "hello"，纹丝不动。相当于你朋友把旧笔记本上的字抄到一本新笔记本上，你的旧笔记本内容不受影响。

---

**🌱 给你的话：**
理解可变与不可变，就像理解“分享”和“复制”的区别。这个认知会帮你避免很多微妙的 bug，你已经走在正确的路上了，继续加油！
