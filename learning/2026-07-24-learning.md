**课程：** Python  
**知识点：** 条件判断与逻辑运算符 (`and`, `or`, `not`)

**题目：**  
请阅读以下代码，判断 `result` 的值是什么？（选择题）

```python
age = 20
has_id = False

result = (age >= 18) and (has_id or not has_id)
print(result)
```

A. `True`  
B. `False`  
C. `None`  
D. 会报错

---

**答案解析：**  
正确答案是 **A. `True`**。

我们来一步步拆解：
1. `(age >= 18)` → 20 >= 18 → **True**
2. `(has_id or not has_id)` → 这是逻辑学里的“排中律”：一个命题和它的否定，总有一个为真。具体来说：
   - `has_id` = False
   - `not has_id` = True
   - False or True = **True**
3. 最终：True and True = **True**

这个例子看起来很“绕”，但它恰恰展示了逻辑运算的优雅之处：`has_id or not has_id` 永远为 True，无论 `has_id` 是什么值。这种技巧在你未来写更健壮的条件判断时，会很有用。

---

**简答题（选做）：**  
如果我想让代码变成：**“只有年龄≥18 并且 持有身份证”的人才能通过**，请问 `result` 这一行应该怎么改？

---

**提示：**  
你只需要把 `or` 改成 `and`，把 `not` 去掉：

```python
result = (age >= 18) and has_id
```

这样当 `has_id = False` 时，结果就是 `False` 了。
