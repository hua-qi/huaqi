### 📝 题目 1（选择题）

以下 Python 代码运行后，`result` 的值是什么？

```python
score = 85
if score >= 90:
    result = "优秀"
elif score >= 80:
    result = "良好"
elif score >= 70:
    result = "中等"
else:
    result = "加油"
```

A. "优秀"  
B. "良好"  
C. "中等"  
D. "加油"

### 📝 题目 2（简答题）

请用 `if-elif-else` 和逻辑运算符 `and` / `or` 写一段代码：  
判断一个数字 `num` 是否在 10 到 20 之间（含端点），如果是，打印 `"在范围内"`，否则打印 `"不在范围内"`。

---

### ✅ 答案解析

**题目 1 答案：B. "良好"**

- `score = 85`，首先判断 `score >= 90` → 不成立
- 接着判断 `elif score >= 80` → 85 >= 80，成立
- 所以 `result = "良好"`
- 注意：`if-elif` 是**按顺序依次判断**，一旦某个条件满足，后续的 `elif` 和 `else` 都会被跳过。

**题目 2 参考代码：**

```python
num = 15  # 你可以改这个值测试

if num >= 10 and num <= 20:
    print("在范围内")
else:
    print("不在范围内")
```

关键点：`and` 表示“且”，两个条件必须同时成立。也可以写成 `10 <= num <= 20`（Python 特有的链式比较）。
