### 复习题：Python 流程控制

**题目：**
请阅读以下代码，写出它的输出结果：

```python
count = 0
for i in range(5):
    if i == 2:
        continue
    if i == 4:
        break
    count += i
print(count)
```

---

**答案解析：**

我们逐步拆解：

1.  `range(5)` 会生成 `0, 1, 2, 3, 4` 这五个数字。
2.  当 `i = 0` 时，不满足任何条件，`count` 加上 0，`count = 0`。
3.  当 `i = 1` 时，`count` 加上 1，`count = 1`。
4.  当 `i = 2` 时，遇到 `continue`，**跳过本次循环**，`count` 不变。
5.  当 `i = 3` 时，`count` 加上 3，`count = 4`。
6.  当 `i = 4` 时，遇到 `break`，**立即结束整个循环**。

所以，最终输出结果是 **`4`**。

**核心考点**：`continue` 是跳过当前这一步，而 `break` 是终止整个循环。这两个词是流程控制的灵魂，一定要分清。

---

**补充一道小思考：**
如果我把 `break` 换成 `continue`，输出会变成多少？（答案：`1 + 3 = 4`，但循环会走完，结果仍是 `4`，但逻辑路径不同。你可以想想为什么结果一样？）
