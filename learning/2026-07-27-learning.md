**题目1（选择题）：**  
以下代码的输出是什么？
```python
a = 5
b = 10
result = a > 3 and b < 15 or not (a == 5)
print(result)
```
A. True  
B. False  
C. 5  
D. 报错

**题目2（简答题）：**  
写一个简单的Python代码，使用`if-elif-else`结构判断一个整数是正数、负数还是零。要求：输入变量为`num`，分别打印"正数"、"负数"或"零"。

---

**答案解析：**

**题目1答案：A. True**  
解析：  
- `a > 3` → `True`（5>3成立）  
- `b < 15` → `True`（10<15成立）  
- `a > 3 and b < 15` → `True and True` → `True`  
- `not (a == 5)` → `not True` → `False`  
- 最终：`True or False` → `True`  
注意运算优先级：`not` > `and` > `or`，所以先算`not`部分。

**题目2参考代码：**
```python
num = -3  # 假设输入值
if num > 0:
    print("正数")
elif num < 0:
    print("负数")
else:
    print("零")
```
