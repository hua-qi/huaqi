**知识点：逻辑运算符的短路求值**

---

**题目1（选择题）：**
```python
x = 0
y = 5
result = x and y
```
`result`的值是多少？
A) 0
B) 5
C) True
D) False

**题目2（简答题）：**
请解释以下代码的输出结果，并说明原因：
```python
def check():
    print("函数被调用了")
    return True

a = 0
b = a or check()
print(b)
```

---

**答案解析：**

**题目1：** 选 A) 0
`and`运算符有短路特性：当第一个操作数为`False`（0、None、空值等）时，直接返回第一个操作数，不再计算第二个。这里`x=0`被视为`False`，所以`result`直接得到`0`。

**题目2：** 输出为：
```
函数被调用了
True
```
原因：`or`运算符也是短路求值。当第一个操作数`a=0`为`False`时，它会继续计算第二个操作数`check()`，所以函数被调用并输出"函数被调用了"，而`check()`返回`True`，所以`b`被赋值为`True`。
