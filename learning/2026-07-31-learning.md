**课程**：Python 基础  
**知识点**：`and` / `or` 的短路求值（Short-circuit Evaluation）

---

**题目**（简答+代码题）：

```python
def check_user(name, age):
    if name and age >= 18:
        return f"{name} 可以进入"
    return "无法进入"

# 问题1：调用 check_user("", 20) 时，会发生什么？
# 问题2：调用 check_user("小明", 16) 时，会发生什么？
```

请写出两次调用的返回值，并解释为什么。

---

**答案与解析**：

- `check_user("", 20)` → 返回 `"无法进入"`  
  **原因**：`name and age >= 18` 中，`name` 是空字符串（falsy），`and` 遇到第一个 falsy 值就**短路**，直接返回 `""`，后面的 `age >= 18` 根本不会执行。所以整个条件为假。

- `check_user("小明", 16)` → 返回 `"无法进入"`  
  **原因**：`name` 是非空字符串（truthy），继续判断 `age >= 18`，`16 >= 18` 为 False，所以整个表达式为 False。

**核心要点**：`and` 只要左边是 falsy 就停止；`or` 只要左边是 truthy 就停止。这个特性在写防御性代码时非常有用——比如 `data = user_input or "默认值"`。
