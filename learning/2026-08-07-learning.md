---

**知识点：** Python 中，`for` 循环可以搭配 `else`。`else` 中的代码会在**循环正常结束**（没有被 `break` 中断）时执行。

---

### 题目（简答题）

阅读下面的代码，写出输出结果，并解释原因：

```python
for i in range(5):
    if i == 3:
        break
else:
    print("循环正常结束")

print("程序结束")
```

---

### 解析

**输出结果：**
```
程序结束
```

**原因：** 当 `i == 3` 时，`break` 语句中断了循环，因此 `else` 块**不会**执行。程序直接跳到循环外的 `print("程序结束")`。

**关键区分：**
- 如果循环**正常跑完**（没有被 `break` 打断），`else` 会执行。
- 如果循环被 `break` 打断，`else` 不会执行。
