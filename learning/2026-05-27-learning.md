**知识点：可变对象 vs 不可变对象**（列表 vs 字符串/元组）

---

### 🧠 题目1（选择题）
以下代码执行后，`a` 的值是什么？
```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```
A. `[1, 2, 3]`  
B. `[1, 2, 3, 4]`  
C. 报错  
D. `[1, 2, 4]`

### 🧠 题目2（简答题）
请写出下面代码的输出结果，并解释原因：
```python
x = "hello"
y = x
y = y + " world"
print(x)
print(y)
```

---

### ✅ 答案解析

**题目1答案：B**
- 列表是**可变对象**。`b = a` 并没有创建新列表，而是让 `b` 指向了 `a` 的同一块内存。
- 修改 `b` 时，`a` 也会同步改变，因为它们是同一个对象。
- 所以 `a` 变成了 `[1, 2, 3, 4]`。

**题目2答案：**
- 输出：`hello` 和 `hello world`
- 字符串是**不可变对象**。`y = x` 让 `y` 指向 "hello"。
- `y = y + " world"` 会创建一个**新的字符串对象** "hello world"，并让 `y` 指向这个新对象。
- `x` 依然指向原来的 "hello"，不受影响。
