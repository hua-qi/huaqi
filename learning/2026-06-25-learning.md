**题目**：

以下 Python 代码的输出是什么？

```python
x = 10
y = 20
z = 15

if x < y and y > z:
    print("A")
elif x > z or y < z:
    print("B")
else:
    print("C")
```

A. A  
B. B  
C. C  

---

**解析**：  
- `x < y` 是 `True`（10 < 20）  
- `y > z` 是 `True`（20 > 15）  
- `True and True` 结果是 `True`，所以直接进入第一个 `if` 分支，输出 `A`。  
- 注意：`elif` 和 `else` 都不会被执行，因为条件已经满足。

**答案**：A
