**📚 课程知识点：Python 基础语法 - 条件判断与逻辑运算**

你刚学完 `if/elif/else` 和 `and`、`or`、`not` 这些逻辑运算符。它们就像程序里的“交通信号灯”，让代码能根据不同的情况走不同的路。

**📝 复习题**

**题目1（选择题）：**  
以下代码运行后，`result` 的值是什么？
```python
age = 20
has_id = False

if age >= 18 and has_id:
    result = "允许进入"
elif age >= 18 and not has_id:
    result = "需要出示证件"
else:
    result = "禁止进入"
```
A. "允许进入"  
B. "需要出示证件"  
C. "禁止进入"

**题目2（简答题）：**  
请用 `if/elif/else` 写一段代码：  
如果 `score` 大于等于 90，打印 "优秀"；  
如果 `score` 在 60 到 89 之间，打印 "及格"；  
否则打印 "不及格"。（提示：可以使用 `and` 或者区间写法）

---

**🔍 答案解析**

**题目1 答案：B. "需要出示证件"**  
- `age >= 18` 为 `True`，`has_id` 为 `False`  
- 第一个条件 `age >= 18 and has_id` → `True and False` → `False`，不执行  
- 第二个条件 `age >= 18 and not has_id` → `True and True` → `True`，执行 `result = "需要出示证件"`

**题目2 参考代码：**
```python
score = 85  # 假设值

if score >= 90:
    print("优秀")
elif score >= 60 and score <= 89:
    print("及格")
else:
    print("不及格")
```
或者更简洁的写法（Python 支持链式比较）：
```python
if score >= 90:
    print("优秀")
elif 60 <= score <= 89:
    print("及格")
else:
    print("不及格")
```
