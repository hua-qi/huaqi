**题目1（选择题）：**
以下代码的输出结果是什么？
```python
count = 0
for i in range(1, 6):
    if i % 2 == 0:
        count += i
    else:
        continue
print(count)
```

A. 6  
B. 9  
C. 15  
D. 0  

**题目2（简答题）：**
请用Python写一段代码：用户输入一个数字n，程序打印出1到n之间所有能被3整除的数。如果n小于1，则输出"请输入正整数"。

---

**答案解析：**

**题目1：** 选 **A. 6**  
解释：`range(1,6)` 生成1,2,3,4,5。`i % 2 == 0` 筛选出偶数（2,4），`count += i` 累加得到 2 + 4 = 6。`continue` 只是跳过奇数，不影响结果。

**题目2 参考代码：**
```python
n = int(input("请输入一个数字: "))
if n < 1:
    print("请输入正整数")
else:
    for i in range(1, n+1):
        if i % 3 == 0:
            print(i)
```
关键点：边界判断、循环范围、取模运算。
