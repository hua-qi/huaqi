**题目1（选择题）：**
执行以下代码后，`result` 的值是什么？
```python
a = 0
b = 5
result = a and b
```
A. 0  
B. 5  
C. True  
D. False  

**题目2（简答题）：**
请解释为什么下面的代码会打印 `"不执行"` 而不是 `"执行"`？
```python
x = None
if x and x > 0:
    print("执行")
else:
    print("不执行")
```

---

**答案解析：**

**题目1 答案：A. 0**
- `and` 是短路运算符：如果第一个操作数为 `False`（或等价于 `False` 的值，如 `0`、`None`、空字符串等），则直接返回第一个操作数，不再计算第二个。
- 这里 `a = 0` 等价于 `False`，所以 `result` 直接等于 `a` 的值 `0`。

**题目2 解析：**
- `x = None` 在布尔上下文中等价于 `False`。
- 在 `if x and x > 0` 中，Python 先判断 `x` 是否为真。因为 `x` 是 `None`（假值），短路逻辑生效，直接跳过 `x > 0` 的判断。
- 这不仅避免了执行 `x > 0`（如果 `x` 是 `None`，直接比较会抛出 `TypeError`），还让条件整体为假，所以走 `else` 分支。
