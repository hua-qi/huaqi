## 📚 课程：Python基础 - 流程控制与逻辑运算
**知识点：逻辑运算符的短路求值**

Python中的 `and` 和 `or` 运算符有一个很实用的特性——**短路求值**。当表达式的结果已经可以确定时，Python会停止计算剩余部分。

### 题目1（简答题）
```python
x = 0
y = 10
result = x and y
print(result)  # 输出是什么？为什么？
```

### 题目2（选择题）
以下代码的输出是？
```python
a = 5
b = 0
c = 3
print(a or b and c)
```
A) 5  
B) 0  
C) 3  
D) True

---

## 💡 答案解析

**题目1：**
输出是 `0`。
因为 `x = 0` 在布尔上下文中是 `False`，`and` 运算符遇到第一个假值就立即返回该值，不再计算 `y`。这就是短路求值——Python知道结果已经确定是假，所以直接返回 `x`。

**题目2：**
答案是 **A) 5**。
这里要记得运算符优先级：`and` 优先级高于 `or`，所以 `b and c` 先计算（结果是 `0`），然后 `a or 0` 中，`a = 5` 是真值，短路返回 `5`。
