### 题目 1（选择题）

以下代码的输出结果是什么？
```python
x = 10
y = 20
result = x > 5 and y < 15 or x == 10
print(result)
```

A) True  
B) False  
C) 语法错误  
D) 10

### 题目 2（简答题）

请用一段 Python 代码实现：判断一个年份是否为闰年。
（闰年规则：能被4整除但不能被100整除，或者能被400整除）
要求：使用 `if-elif-else` 结构，并输出 "是闰年" 或 "不是闰年"。

---

### 答案解析

**题目 1 解析：**
答案是 **A) True**。
运算顺序是：先算 `and`，再算 `or`。
- `x > 5` → True
- `y < 15` → False
- `True and False` → False
- `x == 10` → True
- `False or True` → True

**题目 2 参考代码：**
```python
year = int(input("请输入年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")
```
