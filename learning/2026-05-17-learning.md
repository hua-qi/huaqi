### 复习题 1（选择题）

以下代码的输出是什么？

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以入场")
elif age >= 18 and not has_ticket:
    print("请先购票")
else:
    print("未成年人禁止入场")
```

A. 可以入场  
B. 请先购票  
C. 未成年人禁止入场  
D. 代码会报错

### 复习题 2（简答题）

请用 Python 写一段代码，实现如下功能：

- 如果用户输入的分数 `score` 在 90 分及以上，输出“优秀”
- 如果分数在 60 到 89 之间（含两端），输出“及格”
- 否则输出“不及格”
- **要求**：必须使用 `and` 或 `or` 中的至少一个逻辑运算符。

---

### ✅ 答案解析

**第1题：正确答案是 A**

- `age >= 18` 为 `True`，`has_ticket` 为 `True`
- `True and True` 结果为 `True`，所以进入第一个分支，打印“可以入场”
- 注意：`not has_ticket` 是 `False`，所以 elif 条件不成立

**第2题参考代码：**

```python
score = int(input("请输入分数："))

if score >= 90:
    print("优秀")
elif score >= 60 and score <= 89:
    print("及格")
else:
    print("不及格")
```

或者更简洁地用 `elif 60 <= score <= 89:`，但题目要求使用逻辑运算符，所以上面用 `and` 的写法符合要求。
