**题目 1（选择题）：**
以下代码的输出结果是什么？
```python
x = 10
y = 20
z = 30

if x > y and z > y:
    print("A")
elif x < y and z > y:
    print("B")
else:
    print("C")
```
A. "A"  
B. "B"  
C. "C"  
D. 报错

**题目 2（简答题）：**
请写一个 Python 程序，判断一个年份是否为闰年。  
（提示：年份能被4整除但不能被100整除，或者能被400整除）

---

**答案解析：**

**题1：** 选 B。  
- `x > y and z > y` → `10 > 20` 为 False，所以整个条件为 False  
- `x < y and z > y` → `10 < 20` 为 True 且 `30 > 20` 为 True，整体为 True，输出 "B"

**题2：** 参考代码：
```python
year = 2024
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")
```
关键点：逻辑运算符 `and` 和 `or` 的组合使用，以及取模运算 `%`。
