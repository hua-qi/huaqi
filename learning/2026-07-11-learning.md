**题目1（选择题）**  
以下代码的输出是什么？
```python
x = 5
y = 10
result = x > 3 and y < 15 or not x == 5
print(result)
```
A. True  
B. False  
C. 报错  
D. 不确定

**题目2（简答题）**  
请用 `if-elif-else` 写一段代码：根据用户输入的分数（0-100），输出等级：  
- 90分以上：优秀  
- 60-89分：及格  
- 60分以下：不及格  

假设输入已经是一个整数变量 `score`。

---

**答案解析**  
- **题目1**：正确答案是 **B. False**。  
  逻辑运算优先级：`not` > `and` > `or`。  
  先算 `not x == 5` → `not True` → `False`。  
  然后 `x > 3 and y < 15` → `True and True` → `True`。  
  最后 `True or False` → `True`。等等，我算错了！让我重新来：  
  - `x > 3` → `True`  
  - `y < 15` → `True`  
  - `not x == 5` → `not True` → `False`  
  - 先算 `True and True` → `True`  
  - 再算 `True or False` → `True`  
  所以正确答案是 **A. True**。抱歉，刚才脑子短路了😅 这里的关键是记住 `not` 优先级最高，其次是 `and`，最后是 `or`。

- **题目2**：参考代码：
```python
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```
注意：条件顺序很重要，从高到低排列可以避免逻辑漏洞。
