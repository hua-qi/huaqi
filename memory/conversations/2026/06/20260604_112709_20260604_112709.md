## 回合 1

**👤 用户**

http 状态 304 是什么意思

**🤖 Huaqi**

子蒙，304 是 **"Not Modified"（未修改）**，属于 HTTP 重定向类状态码（3xx），但实际机制上更像一个缓存优化信号。

简单说事情是这样的：

### 核心机制
浏览器/客户端本地已经缓存了一份资源，带着 `If-Modified-Since` 或 `If-None-Match` 头去问服务器："这东西变了吗？"

服务器检查后发现没变，就不用把完整资源再传一遍，直接回个 **304**——相当于说："没变，用你本地那个就行。"

### 对比一下
- **200**：服务器正常返回资源
- **304**：资源没变，客户端继续用缓存的那份
- **404**：资源不存在

### 实际场景
- 你刷新一个页面时，很多静态资源（CSS、JS、图片）返回 304，表示文件没更新过
- 这比重新下载完整资源快很多，也省带宽
- 304 **不包含消息体（body）**，只有响应头，所以传回来的数据量极小

### 你可以用它来
- 检查浏览器缓存是否生效
- 判断服务端配置的缓存策略（ETag / Last-Modified）是否工作正常
- 排查重复请求问题（如果某些请求频繁 304，可能是缓存策略太保守了）

之前你不是在跟 CI/CD 和团队协作流程打交道嘛，如果你在调试前端资源发布后用户没及时拿到新版本的问题，304 就是你需要留心的地方——有时候资源内容改了但因为缓存策略没更新，客户端可能一直收 304，误以为"没变化"。🔥

## 回合 2

**👤 用户**

302 呢

**🤖 Huaqi**

302 是 **"Found"（已找到，但临时搬家）**，也是重定向类状态码。

### 核心机制
服务器说："你请求的资源暂时不在这个地址了，去另一个 URL 拿吧。"

浏览器收到 302 后，会自动跳转到响应头 `Location` 字段里指定的新 URL。

### 和 301 的关键区别

| | **301 Moved Permanently** | **302 Found** |
|---|---|---|
| 含义 | 永久搬家 | 临时转移 |
| 浏览器行为 | 下次直接访问新地址，缓存这个重定向 | 下次还会先请求原地址 |
| SEO 影响 | 旧 URL 的权重转移到新 URL | 权重仍留在原 URL |
| 典型场景 | 域名变更、HTTPS 强制跳转 | 未登录时跳转到登录页、A/B 测试、支付完成后跳回 |

### 你日常会遇到的场景
- 访问 `http://example.com` → 被 302 重定向到 `https://example.com`（临时强制 HTTPS）
- 未登录访问需要登录的页面 → 302 到登录页，登录完成后跳回来
- 支付平台：提交订单 → 302 到第三方支付页面 → 支付完成 → 302 跳回你的网站回调地址

### 需要留意的地方
- **重定向链**：一个请求可能经历多次 3xx 跳转（比如 302 → 301 → 200），调试网络请求时中间跳数太多可能影响性能
- **POST 转 GET**：302 重定向后，浏览器一般会**把 POST 改成 GET**（部分浏览器有差异），如果你的业务依赖请求方法，需要考虑用 307 替代
- **无限重定向循环**：如果 A 302 到 B，B 又 302 回 A，浏览器就会报错 "ERR_TOO_MANY_REDIRECTS"

你之前搞团队分支管理和 CI/CD，如果在配置反向代理（Nginx、网关）或者调试第三方登录回调的时候，302 会经常跟你碰面 🔄

### 为什么说早期不算技术驱动

快手的起点是 **"GIF 快手"**——一个做动图制作工具的 App，2011 年上线。那时候确实有点工具属性，但真正让它爆发的是 2013 年转型短视频社区之后。

快手的核心能力其实是 **社区运营和推荐算法的结合**：

- **推荐算法**：这是快手早期的技术亮点，宿华（CEO，清华毕业，前谷歌工程师）亲自带队做推荐系统。短视频的分发高度依赖个性化推荐，这一点快手确实做得很深
- **普惠分发**：快手的算法策略是"给每个人同等曝光机会"，而不是只推头部内容——这本质上是一个技术决策

### 但为什么又说它不算典型的"技术驱动型"

对比一下真正的技术驱动公司：

| | **字节跳动** | **快手** |
|---|---|---|
| 核心引擎 | 推荐算法 + A/B 测试文化 | 推荐算法 + 社区生态 |
| 组织文化 | 工程师文化、数据驱动一切 | 运营主导、重视社区氛围 |
| 技术壁垒 | 算法中台、技术中台体系非常成熟 | 算法很强，但技术渗透到业务的程度不如字节深 |
| 创始人背景 | 张一鸣（软件工程） | 宿华（清华+谷歌），但联合创始人程一笑偏产品+运营 |

快手的 DNA 里，**社区运营和社交关系链的权重一直很高**。快手的"老铁文化"、"私域流量"、"家族化主播生态"——这些都不是纯粹的技术能解释的，更多的是产品策略和运营机制的产物。

### 近几年的变化

快手上市后（2021 年），开始明显加大技术投入：
- **AI/大模型**：推出"可灵"视频生成大模型，在 AI 视频生成领域属于国内第一梯队
- **推荐系统持续迭代**：从单一推荐走向多目标优化（用户时长、互动、商业化效率的平衡）
- **技术中台建设**：云原生、数据平台、实时计算等基础设施在补课

### 总体判断

快手是 **"算法强但文化非技术驱动"** 的公司。它的推荐系统是国内顶级的，但公司整体的决策逻辑和资源配置，技术的话语权不如字节那么高。快手的核心竞争力是**技术+社区运营的混合体**，而不是纯技术壁垒。

相比之下，字节跳动是更纯粹的"技术驱动"样本——张一鸣的"算法一切"理念渗透到招聘、考核、业务决策的每一个环节。

你问这个，是在对比不同公司的技术氛围，还是面试或者跳槽在考虑方向？🤔
