## 一、防抖 (Debounce)

**场景**：搜索框输入、窗口resize结束后的操作

**核心思想**：触发事件后 **n 秒内**再次触发，**重新计时**

```javascript
function debounce(fn, delay = 300) {
  let timer = null
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, args)
    }, delay)
  }
}
```

**面试官追问**：如果我想**先执行一次**再进入防抖模式呢？
```javascript
// 加个 immediate 参数
function debounce(fn, delay = 300, immediate = false) {
  let timer = null
  return function (...args) {
    const callNow = immediate && !timer
    clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      if (!immediate) fn.apply(this, args)
    }, delay)
    if (callNow) fn.apply(this, args)
  }
}
```

## 二、节流 (Throttle)

**场景**：滚动加载、拖拽、频繁点击

**核心思想**：**规定时间内只执行一次**

### 时间戳版（第一次立即执行，最后一次不执行）
```javascript
function throttle(fn, delay = 300) {
  let lastTime = 0
  return function (...args) {
    const now = Date.now()
    if (now - lastTime >= delay) {
      lastTime = now
      fn.apply(this, args)
    }
  }
}
```

### 定时器版（第一次延迟执行，最后一次会执行）
```javascript
function throttle(fn, delay = 300) {
  let timer = null
  return function (...args) {
    if (timer) return
    timer = setTimeout(() => {
      fn.apply(this, args)
      timer = null
    }, delay)
  }
}
```

**面试官加分点**：说出两者的区别：
- 时间戳版：**第一次立即执行**，**最后一次被忽略**
- 定时器版：**第一次延迟执行**，**最后一次会补上**

## 三、深拷贝

**场景**：拷贝多层嵌套的对象，不影响原对象

```javascript
function deepClone(obj, map = new WeakMap()) {
  // 处理 null 和非对象
  if (obj === null || typeof obj !== 'object') return obj
  
  // 处理循环引用
  if (map.has(obj)) return map.get(obj)
  
  // 处理 Date、RegExp 等特殊对象
  if (obj instanceof Date) return new Date(obj)
  if (obj instanceof RegExp) return new RegExp(obj)
  
  // 创建新对象（保留原型）
  const clone = Array.isArray(obj) ? [] : Object.create(Object.getPrototypeOf(obj))
  map.set(obj, clone)
  
  // 递归拷贝所有属性（包括 Symbol 属性）
  for (const key of [...Object.keys(obj), ...Object.getOwnPropertySymbols(obj)]) {
    clone[key] = deepClone(obj[key], map)
  }
  
  return clone
}
```

**面试官考点**：
1. ✅ **循环引用**（WeakMap解决，为什么用WeakMap？因为不会被拷贝对象持有引用，可自动GC）
2. ✅ **特殊类型**：Date、RegExp、Map、Set
3. ✅ **Symbol 属性**也要拷贝
4. ✅ **原型链保留**（`Object.create(Object.getPrototypeOf(obj))`）

如果面试官说不用考虑太复杂的情况，写一个「面试精简版」就够了：

```javascript
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj
  if (map.has(obj)) return map.get(obj)
  
  const clone = Array.isArray(obj) ? [] : {}
  map.set(obj, clone)
  
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], map)
    }
  }
  return clone
}
```

## 四、手写 Promise（核心版）

面试官最常考的是 **Promise A+ 规范的核心实现**，但二面一般不要求100%完整，写出 **resolve、reject、then、链式调用** 就够了：

```javascript
class MyPromise {
  static PENDING = 'pending'
  static FULFILLED = 'fulfilled'
  static REJECTED = 'rejected'

  constructor(executor) {
    this.status = MyPromise.PENDING
    this.value = undefined
    this.reason = undefined
    this.onFulfilledCallbacks = []
    this.onRejectedCallbacks = []

    const resolve = (value) => {
      if (this.status === MyPromise.PENDING) {
        this.status = MyPromise.FULFILLED
        this.value = value
        this.onFulfilledCallbacks.forEach(fn => fn())
      }
    }

    const reject = (reason) => {
      if (this.status === MyPromise.PENDING) {
        this.status = MyPromise.REJECTED
        this.reason = reason
        this.onRejectedCallbacks.forEach(fn => fn())
      }
    }

    try {
      executor(resolve, reject)
    } catch (err) {
      reject(err)
    }
  }

  then(onFulfilled, onRejected) {
    // 处理参数透传：Promise.resolve(1).then().then(res => console.log(res))
    onFulfilled = typeof onFulfilled === 'function' ? onFulfilled : val => val
    onRejected = typeof onRejected === 'function' ? onRejected : err => { throw err }

    const promise2 = new MyPromise((resolve, reject) => {
      // 包装执行函数，处理返回值可能是 Promise 的情况
      const handleCallback = (callback, value) => {
        // 实现异步微任务（简化版用 setTimeout）
        setTimeout(() => {
          try {
            const result = callback(value)
            // 如果返回的是 Promise，递归处理
            if (result instanceof MyPromise) {
              result.then(resolve, reject)
            } else {
              resolve(result)
            }
          } catch (err) {
            reject(err)
          }
        }, 0)
      }

      if (this.status === MyPromise.FULFILLED) {
        handleCallback(onFulfilled, this.value)
      } else if (this.status === MyPromise.REJECTED) {
        handleCallback(onRejected, this.reason)
      } else {
        // PENDING 状态时，把回调存起来
        this.onFulfilledCallbacks.push(() => handleCallback(onFulfilled, this.value))
        this.onRejectedCallbacks.push(() => handleCallback(onRejected, this.reason))
      }
    })

    return promise2
  }

  // 静态方法
  static resolve(value) {
    return new MyPromise((resolve) => resolve(value))
  }

  static reject(reason) {
    return new MyPromise((_, reject) => reject(reason))
  }

  static all(promises) {
    return new MyPromise((resolve, reject) => {
      const results = []
      let count = 0
      promises.forEach((p, i) => {
        MyPromise.resolve(p).then(res => {
          results[i] = res
          count++
          if (count === promises.length) resolve(results)
        }, reject)
      })
    })
  }

  static race(promises) {
    return new MyPromise((resolve, reject) => {
      promises.forEach(p => {
        MyPromise.resolve(p).then(resolve, reject)
      })
    })
  }
}
```

**面试官关注点**：
1. ✅ **状态不可逆**：PENDING → FULFILLED / REJECTED，不能回头
2. ✅ **then 返回新 Promise**（链式调用的关键）
3. ✅ **值的穿透**：`.then().then(val => ...)` 中间没传函数也能传值
4. ✅ **异步处理的缓存机制**（pending时存回调数组）

## Promise 到底是什么？

一句话：**Promise 是一个用于处理异步操作的对象，代表一个未来才会完成的操作的结果。**

核心就三个状态：

```
Pending（进行中） → Fulfilled（已成功）
                  ↘ Rejected（已失败）
```

**状态一旦改变，就不可逆**。你不能从 Fulfilled 变回 Pending，也不能从 Fulfilled 变成 Rejected。

---

## 为什么需要 Promise？

**没有 Promise 之前**，写异步代码是这样的——回调地狱：

```javascript
getUser(1, function(user) {
  getPosts(user.id, function(posts) {
    getComments(posts[0].id, function(comments) {
      console.log(comments)  // 一层套一层，维护噩梦
    })
  })
})
```

**有了 Promise 之后**：

```javascript
getUser(1)
  .then(user => getPosts(user.id))
  .then(posts => getComments(posts[0].id))
  .then(comments => console.log(comments))
  .catch(err => console.error(err))  // 错误统一处理
```

**好处就是**：
1. ✅ **链式调用**——扁平化，可读性强
2. ✅ **错误统一处理**——一个 `.catch` 捕获所有
3. ✅ **控制反转**——你不再把回调交给别人，而是拿到一个 Promise 自己控制

## 关键概念：微任务

Promise 是**微任务（microtask）**，不是宏任务。这意味着它的优先级比 setTimeout 高：

```javascript
console.log(1)

setTimeout(() => console.log(2), 0)

Promise.resolve().then(() => console.log(3))

console.log(4)

// 输出顺序：1 → 4 → 3 → 2
// 为什么？同步代码先执行 → 微任务(Promise.then) → 宏任务(setTimeout)
```

## 核心用法全景

```javascript
// 1. 创建一个 Promise
const p = new Promise((resolve, reject) => {
  // 异步操作
  setTimeout(() => {
    const success = true
    if (success) {
      resolve('成功了')  // 进入 Fulfilled 状态
    } else {
      reject('失败了')   // 进入 Rejected 状态
    }
  }, 1000)
})

// 2. 消费这个 Promise
p.then(
  (value) => console.log(value),  // 成功的回调
  (reason) => console.log(reason) // 失败的回调
)
```

## 必须掌握的静态方法

```javascript
// Promise.resolve —— 快速返回一个成功的 Promise
Promise.resolve(42).then(val => console.log(val)) // 42

// Promise.reject —— 快速返回一个失败的 Promise
Promise.reject('出错了').catch(err => console.log(err)) // 出错了

// Promise.all —— 全部成功才成功，一个失败就失败
const promises = [fetch('/a'), fetch('/b'), fetch('/c')]
Promise.all(promises).then(([resA, resB, resC]) => {
  // 三个请求都完成了才会到这里
}).catch(err => {
  // 任何一个请求失败就到这里
})

// Promise.race —— 谁先到就听谁的
Promise.race([fetch('/fast'), fetch('/slow')]).then(res => {
  // 返回最快的那个结果
})

// Promise.allSettled —— 不关心成功失败，等所有人完成
Promise.allSettled([fetch('/a'), fetch('/b')]).then(results => {
  // results 是 [{status: 'fulfilled', value: ...}, {status: 'rejected', reason: ...}]
})

// Promise.any —— 只要有任意一个成功就成功，全失败才失败
Promise.any([fetch('/a'), fetch('/b')]).then(res => {
  // 返回第一个成功的
})
```

## 面试常见追问

**Q：Promise 为什么能链式调用？**
A：因为 `.then()` 返回的是一个新的 Promise。不是返回 `this`，而是 `new Promise()`。所以每次 `.then()` 都是一个新的 Promise 实例。

```javascript
const p1 = new Promise(r => r(1))
const p2 = p1.then(v => v + 1)
console.log(p1 === p2) // false，这是两个不同的 Promise
```

**Q：then 里返回一个普通值和返回一个 Promise 有什么区别？**
```javascript
Promise.resolve(1).then(v => {
  return v + 1          // 自动被包装成 Promise.resolve(2)
}).then(v => {
  return new Promise(r => setTimeout(() => r(v + 1), 1000))
  // 返回 Promise，那么下一个 then 会等它 resolve 后才执行
})
```

**Q：catch 和 then 的第二个参数有什么区别？**
```javascript
// 方式一：then 第二个参数
p.then(
  val => { /* 成功处理 */ },
  err => { /* 失败处理 */ }  // 只能捕获当前 Promise 的错误
)

// 方式二：catch
p.then(val => { /* 成功处理 */ })
 .catch(err => { /* 失败处理 */ }) // 可以捕获前面所有 then 的错误

// 区别：catch 能捕获前面 then 里抛出的错误，而 then 第二个参数不能
```

**Q：async/await 和 Promise 的关系？**
```javascript
// async/await 是 Promise 的语法糖
async function fetchData() {
  try {
    const res = await fetch('/api')  // await 后面跟 Promise
    const data = await res.json()
    return data
  } catch (err) {
    console.error(err)
  }
}

// 等价于：
function fetchData() {
  return fetch('/api')
    .then(res => res.json())
    .catch(err => console.error(err))
}
```
