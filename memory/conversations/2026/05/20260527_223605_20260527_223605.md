**常见换行符：**
- `\n` — **LF (Line Feed)**，Unix/Linux/macOS 系统默认
- `\r\n` — **CRLF**，Windows 系统默认
- `\r` — **CR**，旧版 Mac 系统

- CSS 中用 `white-space: pre-line` 或 `pre-wrap` 让文本里的 `\n` 生效
- HTML 里 `<br>` 是换行标签
- JavaScript 字符串里用 `\n` 或模板字面量直接换行
