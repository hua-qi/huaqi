macbook finder 中如何拿到目录的路径

**🤖 Huaqi**

子蒙，在 macOS Finder 里拿目录路径有好几种方法，给你列最常用的几个：

**方法一：拖拽法（最快）**
直接把文件夹拖进「终端」或任何文本输入框，路径会自动填上。

**方法二：右键菜单**
1. 选中文件夹
2. 按住 **Option 键**
3. 右键点击 → 你会看到「将"xxx"拷贝为路径名称」
4. 点击后路径就复制到剪贴板了 ✌️

**方法三：显示简介**
1. 选中文件夹，按 `Cmd + I`
2. 在弹出的信息窗口底部，找到「位置」那一行
3. 可以手动复制

**方法四：终端 pwd（如果你已经在终端里）**
```bash
cd 到那个目录
pwd
```
然后复制输出。

**方法五（我私心推荐的一个）：**
把 Finder 的路径栏显示出来——
菜单栏「显示」→「显示路径栏」
然后底部会有一条路径，双击任意一层就能跳转，或者直接右键路径区域可以复制。
